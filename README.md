# 🍱 Marmitaria - Gerenciamento de Menu

Aplicação desenvolvida na disciplina de Desenvolvimento de Plataformas Web para gerenciamento de cardápio de uma marmitaria, permitindo o cadastro, edição, ativação/ocultação e exclusão de categorias e pratos, com painel de métricas em tempo real.

🔗 [Link para acessar o site onde o projeto está hospedado](https://gestao-marmitaria.onrender.com)

---

### O sistema conta com:

◦ **Painel de Métricas:** contagem dinâmica de categorias e total de pratos.<br>
◦ **Gestão de Categorias:** criar, editar, ativar/ocultar e excluir categorias.<br>
◦ **Gestão de Pratos:** cadastrar, editar, excluir e alternar disponibilidade para venda, com suporte a upload e remoção de imagem.<br>
◦ **Interface Responsiva e Temas:** layout adaptado para desktop e celular, com alternância entre modo claro e modo escuro.<br>
◦ **Validações no Back-end:** campos obrigatórios, preço maior que zero e prevenção de nomes duplicados.
